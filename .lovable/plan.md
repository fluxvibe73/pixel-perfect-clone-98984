# Clone Eliteztudio website

## Goal
Recreate the complete published Eliteztudio site in Lovable, matching its content, dark cinematic styling, page structure, imagery, videos, navigation, and contact actions.

## Build
- Recreate Home, Work, Services, About, and Contact as separate pages.
- Match the floating black navigation, blue primary actions, large cinematic page openings, typography, spacing, image grids, testimonials, service options, process sections, FAQs, and footers.
- Import the owned images into this project rather than relying on the old website.
- Preserve all nine YouTube portfolio videos and their visible project descriptions.
- Preserve the existing email, WhatsApp, phone, LinkedIn, and Google Maps destinations exactly as published.
- Make navigation and expandable FAQ questions fully functional on desktop and mobile.

## Technical details
- Use the existing Lovable page system with shared site-wide navigation, footer, page-opening, gallery, testimonial, and FAQ building blocks.
- Define the full visual system centrally using semantic colors and typography.
- Add unique search and social-sharing metadata to every page.
- Keep this as a content site; no login or database is needed because neither is present on the published site.

## Verification
- Compare each recreated page against the captured source at desktop and mobile sizes.
- Check all internal pages, external contact links, YouTube embeds, images, and FAQ interactions.
- Confirm no placeholder content or missing media remains.
